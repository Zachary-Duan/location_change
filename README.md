# iPhone 定位控制台

[打开公开网页，下载连接助手](https://zachary-duan.github.io/location_change/)

用 Mac 或 Windows 通过 USB 连接自己的 iPhone，在本机地图上选择测试位置。网站提供助手下载、首次使用指引和本机控制台入口。Windows 助手目前为测试版。

## 在自己的仓库发布副本

1. 在自己的 GitHub 账号下创建一个公开仓库，例如 `iphone-location-pages`。
2. 把此目录中的 `docs` 文件夹和 `README.md` 提交到仓库的 `main` 分支。提交后应当能在仓库中看到 `docs/index.html`，Mac 和 Windows 两个 ZIP 应保留在 `docs/downloads/` 中。
3. 在仓库的 **Settings → Pages** 中选择 **Deploy from a branch**，选 `main` 和 `/docs`，点击 **Save**。
4. 等部署完成，点击同一页面的 **Visit site**。将这个网址分享给访客，后续提交到 `main` 的网页更新会自动发布。

[GitHub Pages 官方发布指引](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)
